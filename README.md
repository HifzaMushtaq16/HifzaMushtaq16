### 👋 A bit about me

I design and ship autonomous AI agents. These are systems that go beyond answering questions by planning, deciding, and taking action. My work focuses on **agent orchestration**, **retrieval-augmented reasoning**, and **cloud-native deployment**. I have also tested these skills in competitive environments, most recently as a finalist at the **USAII Global AI Hackathon 2026**.

- Deep focus on **LangGraph state machines**, **multi-agent architectures**, and **MCP-based deployment**
- Led **Team NeuraForge** to the USAII Global AI Hackathon finals and pitched the project to international judges
- Built a full autonomous B2B quoting pipeline independently for the Qwen Cloud Global AI Hackathon
- Currently developing production-grade patterns for agent reliability and human-in-the-loop control

### 🏗️ What I've been building

<table>
<tr>
<td width="50%" valign="top">

**🧾 QuoteFlow AI**
An autonomous B2B quoting agent that takes an RFQ all the way to a signed-off quote — pricing, risk checks, negotiation, and document generation, no manual handoffs required. Runs on a LangGraph state machine reasoned by Qwen2.5, deployed as an MCP server on Alibaba Cloud, with human approval gates and full audit logging.

`LangGraph` `Qwen2.5` `FastAPI` `MCP` `Alibaba Cloud`

`LangGraph` `RAG` `Streamlit` `LLM APIs`

</td>
</tr>
